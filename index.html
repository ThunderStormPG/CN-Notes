Q5, Q18 Q17

Data Communication Components & Network Definition

Network: Jab do ya do se zyada devices aapas me connect hote hain data share karne ke liye, use network kehte hain.

5 Basic Components:

  • Sender: Jo bhej raha hai (Computer/Mobile).
  • Message: Jo data bhej raha hai (Text/Video).
  • Transmission Medium: Rasta (Cable/Wi-Fi).
  • Protocol: Rules (Jaise TCP/IP).
  • Receiver: Jo le raha hai (Destination).
Mnemonic: "SMTP-R" (Sender, Message, Transmission Medium, Protocol, Receiver)
Q6 Q22

Types of Networks (LAN, MAN, WAN)

  • LAN (Local Area Network): Small area (Room, Building). Example: College lab.
  • MAN (Metropolitan Area Network): City level. Example: Cable TV network.
  • WAN (Wide Area Network): Country/Global. Example: The Internet.
Mnemonic: Little Medium World (LAN < MAN < WAN)
Q7

Latency & Throughput

  • Latency (Delay): Data ko point A se B tak pahunchne me kitna time laga. (Travel time).
  • Throughput (Speed): Actual rate of successful data transfer. (Speed of the car).
Q10 Q23

Network Topologies (Mesh vs Star)

  • Mesh: Har device dusre se juda hai. Example: Military communication. (Pros: Very secure. Cons: Bahut wiring lagti hai).
  • Star: Sab devices ek central Hub/Switch se jude hain. Example: Office network. (Pros: Easy to install. Cons: Central Hub mar gaya toh network dead).
Q1 Q11

OSI Model vs TCP/IP Model

OSI Model (7 Layers - Theoretical):

  1. Physical (Cables)
  2. Data Link (Framing, MAC)
  3. Network (Routing, IP)
  4. Transport (End-to-end, TCP/UDP)
  5. Session (Start/Stop)
  6. Presentation (Encryption)
  7. Application (User interface)
Mnemonic: Please Do Not Throw Sausage Pizza Away

TCP/IP Model (4 Layers - Practical): Network Access, Internet, Transport, Application.

Difference: OSI is theoretical (7 layers), TCP/IP is practical/used in real life (4 layers).

Q2 Q19

Hub vs Switch vs Router

  • Hub: Dumb device, sabko data bhejta hai. Physical Layer.
  • Switch: Smart, sirf target ko bhejta hai (MAC address). Data Link Layer.
  • Router: Connects different networks (LAN to WAN), uses IP. Network Layer.

Note (Q19): Repeater is at Physical Layer, Gateway operates at all layers (mostly Application).

⚙️ Unit 2: Data Link Layer & Error Control

Q8

Duties of Data Link Layer

Major duty: Framing (Packing bits into frames) and Error Control (Checking if data is corrupted).

Q9, Q15, Q21

Stuffing (Bit vs Byte)

Used to distinguish between actual data and control flags.

  • Bit Stuffing: Agar data mein flag (`01111110`) jaisa pattern aa raha hai, toh sender `1` ke baad ek extra `0` daal deta hai.
  • Byte Stuffing: Same concept but with bytes/characters. Extra byte (ESC) insert karte hain.
Q3 Q12

Error Detection: CRC (Cyclic Redundancy Check)

Concept: Data ko generator polynomial se divide karte hain. Remainder hi CRC hota hai.

Steps:

  1. Append Zeros: Generator jitna lamba hai (suppose 4 bits), data ke end mein utne minus 1 (i.e., 3) zeros lagao.
  2. XOR Division: Binary division karo (XOR logic use karo).
  3. Remainder: Jo bacha wo CRC hai.
  4. Codeword: Original Data + CRC.

Exam Tip: Binary XOR calculation zaroor practice karo paper pe.

Q5 Q13

Error Correction: Hamming Code

Rule: Number of parity bits \(r\) formula: \(2^r \geq m + r + 1\) (where \(m\) = data bits).

Steps for Data 10011 (5 bits):

  1. Find r: Try \(r=4\): \(2^4 = 16\), \(5+4+1=10\). \(16 \geq 10\). So, 4 parity bits.
  2. Positions: Parity bits at 1, 2, 4, 8.
  3. Even Parity Calculation: Make total number of 1s even for each group (P1 checks 1,3,5,7,9; P2 checks 2,3,6,7, etc.).
Q14 Q20

ARQ (Automatic Repeat reQuest)

  • Go-Back-N (GBN): Ek packet kharab hua toh us packet se lekar piche ke saare packets dobara bhejta hai.
  • Selective Repeat (SR): Sirf kharab wala packet dobara bheja jata hai.

Q20 Answer: Selective Repeat is more efficient on noisy links because it only retransmits the lost/damaged frames, saving bandwidth.

⚡ Quick Memo Snippets (Ratta Maar)

  • Components: Sender, Receiver, Message, Medium, Protocol.
  • OSI Layers: Physical, Data Link, Network, Transport, Session, Presentation, Application.
  • Devices: Hub (Physical) | Switch (Data Link) | Router (Network).
  • Networks: LAN (Building) | MAN (City) | WAN (World).
  • CRC: Binary Division (XOR). Remainder = CRC.
  • Hamming: \(2^r \geq m+r+1\). Even parity = total 1s even.
  • Topologies: Mesh (Secure, Expensive) | Star (Central Hub, Easy).
  • ARQ: GBN (Resends all) vs SR (Resends only lost). SR is better for noisy links.
